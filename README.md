# Beauty Product Ingredient Checker
A web application that allows users to search for beauty products, view product details, and learn more about ingredients.

## Features
- Search beauty products by name
- View product images, brand names, and ingredient lists
- Click individual ingredients to learn more about them
- Retrieve ingredient descriptions and information from Wikipedia
- Display search results and error messages

## Tech Stack
- HTML
- CSS
- JavaScript
- Open Beauty Facts API
- Wikipedia REST API

## Getting Started
1. Clone this repository:
```
git clone https://github.com/CarlyJovon/med-spa-app.git
```
2. Navigate to the project folder:
```
cd med-spa-app
```
3. Open `index.html` in your browser.

## How It Works
1. Enter a beauty product name in the search bar.
2. The app retrieves product information using the Open Beauty Facts API.
3. View the product image, brand, and ingredient list.
4. Click an ingredient to retrieve additional information from Wikipedia.
